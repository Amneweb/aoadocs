## Términos usados en la guía

| Término                 | Rol/Tarea/Acción | Descripción                                                                                                                                                                                               |
| :---------------------- | :--------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Administrador de club` | `ROL`            | Es una persona designada por un club para tener acceso al `Portal` y eventualmente manejar información referida a un `Evento AOA` organizado por su club                                                  |
| `Adulto responsable`    | `ROL`            | adulto encargado de la administración de los datos de un `Afiliado`                                                                                                                                       |
| `Adulto vinculado`      |                  | adulto relacionado con un `Afiliado`. Sus datos se guardan en la base de datos y son parte de la información personal del `Afiliado`. Generalmente son los padres, familiares y/o contactos de emergencia |
| `Afiliado`              |                  | menor de edad socio de AOA que participa en las competencias; es el eje alrededor del cual se organiza todo el `Portal` de administración                                                                 |
| `Competidor`            |                  | otra manera de referirnos al `Afiliado`                                                                                                                                                                   |
| `Evento AOA`            | `ENTIDAD`        | evento dirigido por AOA, por ejemplo clínicas, selectivos y argentinos                                                                                                                                    |
| `Guardián`              | `ROL`            | puede aparecer en algún lugar de la guía o el `Portal` para referirnos al `Adulto responsable`                                                                                                            |
| `Panel de control`      | `INTERFAZ`       | pantalla principal desde donde navegar a todas las secciones del `Portal`, y en la cual se presenta un resumen de toda la información útil para el `Usuario`                                              |
| `Dashboard`             | `INTERFAZ`       | otra manera de referirnos al `Panel de control` (puede llegar a aparecer en la guía o en el `Portal` mismo)                                                                                               |
| `Rol`                   |                  | "papel" que desempeña un `Usuario` en el `Portal`, que lo habilita a realizar acciones específicas y ver diferente tipo de información                                                                    |
| `Usuario`               | `ENTIDAD`        | Persona con acceso al `Portal` (es decir, que se puede loguear y ver o manipular datos). Es el término general para nombrar a cualquier persona que interactúa con el `Portal`                            |
| `Portal`                |                  | Aplicación web de acceeso restringido para resolver temas administrativos y operacionales de la AOA                                                                                                       |
